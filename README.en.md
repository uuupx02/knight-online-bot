## What can it do?

- **Auto farm:** mob routes, target selection and continuous hunting loops.
- **Class profiles:** separate skill/attack routines for Warrior, Priest, Rogue and Mage.
- **Skill rotation:** cooldown tracking, combo order and target-based skill selection.
- **Survival:** HP/MP potions, buff refresh, escape and return to a safe zone.
- **Item management:** loot filters, inventory cleanup, repair and storage loops.
- **Party support:** buff/heal priority for party members and party farm routines.
- **Multiple characters:** separate profiles and scheduling for multiple clients.
- **Resilience:** reconnect after disconnects, resume after errors.
- **Reporting:** session time, mobs killed, items collected and error logs.

## Class-based profiles

| Class | Automation focus |
|---|---|
| Warrior | Melee rotation, target priority, potion management |
| Priest | Buff/heal loop, party support, safe positioning |
| Rogue | Speed-focused rotation, escape and repositioning |
| Mage | Range control, area skills, mana management |

Profiles are adapted to the character’s level, gear and skill layout; server-specific profiles can be written when needed.

## Farm and session management

- Area routes and a waypoint system.
- Scheduled start/stop windows.
- Return to town, repair and storage when inventory is full.
- Respawn and return to route after death.
- Sequential or parallel operation for multiple accounts.
- Simple panel: start, pause, status, log.

## Technical approach

- Automation layer running on the Windows client.
- Low resource usage and background support.
- Profile files: class, gear, route and skill priorities.
